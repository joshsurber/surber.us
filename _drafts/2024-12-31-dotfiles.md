I have had [my dotfiles](https://github.com/joshsurber/.files) on Github for a while now, but have been really messing with them lately. They contain a few really clever bits that I thought were worth going over. Here are some of my favorite things from my [install scripts](https://github.com/joshsurber/.files/blob/master/makefile)

I often reinstall my OS or set up new devices. I have put instructions to get up and running very quickly in my [readme](https://github.com/joshsurber/.files/blob/master/README.md). This is mostly for my personal use, but is probably useful to others as well. In a nutshell, after a fresh install, I put in my SSH keys from a keydrive I keep on my literal keychain. I then clone my dotfile repo in the next block. I have instructions to copy and paste into either Arch-based distros that use `pacman` or Debian-based distros that use `apt`.

From there I run `make arch` or `make deb` to install all the apps I normally use, set up my dotfiles, install `yay` (on Arch), and do a small bit of extra setup.

Let me go over some clever bits from this setup.

I have two concurrent lists of packages to install, for both [Arch](https://github.com/joshsurber/.files/blob/master/pkgs.arch) and [Debian](https://github.com/joshsurber/.files/blob/master/pkgs.deb). These are simply files with one pachage name per line.

The makefile that controls everything is the first makefile I've ever written, and does several clever things.

For Debian systems, I have `make neovim` to install neovim, as the version in the apt repo is always far out of date.

I also have a [file](https://github.com/joshsurber/.files/blob/master/rclone.txt) for [rclone](https://rclone.org/).
